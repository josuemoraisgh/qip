\section{Revisão Bibliográfica}

O uso de dados sintéticos em saúde e psicologia permite ampliar bases pequenas e preservar privacidade. Entre as principais técnicas:

\begin{itemize}
    \item \textbf{SMOTE}: (Chawla et al., 2002) cria novas amostras minoritárias por interpolação:
    \[
        x_{\text{new}} = x_i + \delta \cdot (x_{nn} - x_i), \quad \delta \sim U(0,1)
    \]

    \item \textbf{GANs}: (Goodfellow et al., 2014) jogo entre Gerador $G(z)$ e Discriminador $D(x)$:
    \[
        \min_G \max_D \; V(D,G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]
    \]

    \item \textbf{WGAN-GP}: (Arjovsky et al., 2017; Gulrajani et al., 2017) substitui divergência por distância de Wasserstein e adiciona penalização de gradiente:
    \[
        L_{GP} = \lambda \; \mathbb{E}_{\hat{x}} \left[ \left(\|\nabla_{\hat{x}} D(\hat{x})\|_2 - 1 \right)^2 \right]
    \]

    \item \textbf{cWGAN}: (Mirza \& Osindero, 2014) adiciona condicionamento no rótulo $y$.

    \item \textbf{Abordagem híbrida (SMOTE + WGAN-GP)}: Wang \& Pai (2023) combinaram SMOTE e WGAN-GP para melhorar dados clínicos tabulares.

    \item \textbf{Privacidade}: (Jordon et al., 2019) destacam filtros de proximidade e ajustes marginais (CDF matching).
\end{itemize}
